FAQ

Frequently Asked Questions

কেন TradingView username লাগবে?

আপনার order-এর জন্য TradingView account শনাক্ত করার প্রয়োজন হতে পারে।

Payment করার পর কী হবে?

Order প্রথমে Pending থাকবে। Payment যাচাইয়ের পর admin order status পরিবর্তন করতে পারবে।

কোন payment method ব্যবহার করা যাবে?

বর্তমানে bKash, Nagad এবং Binance Pay payment method হিসেবে দেওয়া আছে।

Order ID কোথায় পাবো?

Order successfully submit করার পর screen-এ আপনার Order ID দেখানো হবে।

Order status কীভাবে দেখবো?

Order ID নিয়ে নিচের Order Status section-এ গিয়ে Check Status চাপুন।

এটা কি real payment gateway?

এই website বর্তমানে transaction ID গ্রহণ করে। Automatic payment verification চাইলে আলাদা merchant/API integration প্রয়োজন হবে।
